# Tailwind v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Tailwind CSS v4 to this Vite React project and leave a working demo page that visibly proves the integration works.

**Architecture:** Use the official `@tailwindcss/vite` plugin in the existing Vite pipeline, switch the global stylesheet to the Tailwind v4 entry import, and replace the default Vite demo page styling with Tailwind utility classes. This keeps the integration small, avoids legacy config files, and uses the current app entrypoints that already exist in the project.

**Tech Stack:** React 19, TypeScript, Vite 6, Tailwind CSS v4, `@tailwindcss/vite`


- [ ] **Step 3: Keep the rest of the config unchanged**

```ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react-swc';
import tailwindcss from '@tailwindcss/vite';
import requireTransform from 'vite-plugin-require-transform';

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),
    requireTransform({ fileRegex: /\.js$|\.jsx$|\.ts$|\.tsx/ }),
```

```tsx
      <section className="w-full max-w-3xl rounded-3xl border border-white/10 bg-white/5 p-8 shadow-2xl shadow-slate-950/40 backdrop-blur">

        </div>

          <h1 className="text-4xl font-semibold tracking-tight text-white sm:text-5xl">
            React 19 + Vite 6 + Tailwind v4
          </h1>

          <p className="max-w-2xl text-base leading-7 text-slate-300 sm:text-lg">
            This page is styled entirely with Tailwind utility classes so we can verify the
            integration immediately.
          </p>
        </div>

        <div className="mt-10 flex flex-col gap-4 sm:flex-row sm:items-center">

          </button>

          <span className="text-sm text-slate-400">

          </span>
        </div>

  );
}
```
